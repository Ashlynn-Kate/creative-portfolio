# Home hero copy alignment

## Context

The photographic hero sequence established a broad visual field behind the
homepage introduction. The opening copy needed a placement that feels balanced
within that field while retaining the editorial left edge used elsewhere on the
site.

## Decision

Vertically center the eyebrow, name, and descriptive line as one left-aligned
copy block inside the home hero. The composition uses the same placement on
desktop and mobile, with existing responsive type sizes preserved.

## Options considered

- **Top-aligned copy:** preserves more open image area below the text but
  leaves the opening weighted toward the top.
- **Centered copy:** balances the collage but loses the portfolio's left-edge
  editorial rhythm.
- **Vertically centered, left-aligned copy (chosen):** balances the collage
  while preserving the existing typographic alignment.

## Trade-offs

- Pros: gives the opening a calmer focal point and lets the imagery surround
  the copy rather than sit beneath it.
- Cons: leaves less clear area immediately above the hero text for some image
  sequences.

## Revisit if

The hero receives a substantially different image treatment or the copy gains
additional lines.
