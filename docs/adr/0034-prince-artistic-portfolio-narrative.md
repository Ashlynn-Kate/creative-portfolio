# Prince artistic portfolio narrative

## Context

The former project overview, role box, and expandable process notes made the
page read like a job application instead of an artistic portfolio.

## Decision

The Prince of Egypt opens with a focused unheaded introduction, two quiet
credit lines, and an always-visible stage image paired with the Shaping the
Production text. Set-development pages follow directly afterward. The header
uses Direction, Choreography, and Visual Direction pills.

## Options considered

- **Keep overview and accordions:** retains more labelled production detail.
- **Editorial narrative (chosen):** lets artistic direction and process read as one continuous story.

## Trade-offs

- Pros: clearer artistic voice and a calmer, more visual reading order.
- Cons: less information is visible as separately labelled production tasks.

## Revisit if

New archival material needs a dedicated technical-production section.
